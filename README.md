# Navin - Professional Personal Website

A minimal professional portfolio website built with:

- HTML5
- CSS3
- Bootstrap 5.3
- Responsive design
- Semantic sections
- Minimal custom CSS

## Folder structure

personal_professional_website/
├── index.html
├── README.md
└── css/
    └── style.css

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize

Edit `index.html` to replace:

- Professional summary
- Experience
- Projects
- Email address
- LinkedIn URL
- GitHub URL
- Copyright/name

The Bootstrap CSS and JS are loaded from jsDelivr CDN.
